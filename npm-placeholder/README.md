# dsh-vibe-trading

> Interactive trading research, natively on DeepSeek Harness: ask a market question →
> a deterministic pipeline plans, pulls data, computes and explains. **Numbers come
> from code, findings cite their computations.** Terminal brief + zero-dependency
> SVG chart card + auditable trail.
>
> Inspired by HKUDS/Vibe-Trading (not affiliated). Family:
> [dsh-TradingAgents](https://github.com/vicfei/dsh-TradingAgents) ·
> [dsh-ai-hedge-fund](https://github.com/vicfei/dsh-ai-hedge-fund).

**Status: name reserved — first release in development.**

Engine and docs: https://github.com/vicfei/dsh-Vibe-Trading

- A-share / index / US K-lines, zero API keys, CN-cloud friendly
- Stats + mini trend backtest + inline-SVG chart cards (offline-safe)
- Auditable trails: question / plan / computations / findings, every step on disk
- Not investment advice.
